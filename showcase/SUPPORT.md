# Support and Safe Reporting - Local Candidate Draft

This private local candidate has no established public support address, hosted service, guaranteed response time or public issue tracker. Contact the package owner only through a channel that is already authorized. No personal email, invented GitHub URL or security-reporting endpoint is supplied here.

## What can be reported

Report an installation-free example that does not run, a mismatch between documented and actual synthetic output, an unclear limitation or a reproducible documentation problem. Read the [evidence guide](docs/research-evidence.md) before interpreting a result.

An expected FAIL, UNKNOWN or PROPOSED field is not itself a defect. Exit0 can mean that a demonstration completed while showing those fields. Lack of a resource-release receipt leaves release UNKNOWN; it proves neither zero leakage nor a leak.

## Minimal safe report

Include the exact authorized package/version or manifest digest, OS/Python version, current directory, exact command, exit status, expected/actual result and the smallest synthetic case. Retain failure details and identify unobserved facts as UNKNOWN. This guide does not require or authorize a fresh execution.

Share only material that you have authority to disclose. Never post credentials, account identifiers, personal author-review replies, private reference answers, raw Pilot/Rerun records, original research traces or validation/held-out tasks. Redact identifying paths from shared diagnostics, keep an authorized private original, and say what was redacted.

If a possible security problem or accidental disclosure is suspected, stop sharing the affected material and use an existing authorized private channel. Do not open a public issue containing sensitive evidence. A dedicated security policy and verified reporting endpoint have not been established by this package.

## Limits of support evidence

A report is not proof of a general algorithm defect, a human-intent error or a statistical effect. Preserve the command, scope and uncertainty so a separately authorized investigation can distinguish them. Follow the [contribution guide](CONTRIBUTING.md) for bounded changes; no automatic fix, new experiment, public upload or license consent follows from reporting a problem.
